# موقع مراجعة الفلسفة
كل درس صفحة HTML مستقلة في `content/uX-sY.html`، ومحتواه محفوظ داخل الملف نفسه. تتشارك الصفحات ملف التصميم `assets/site.css`، ويضيف `assets/ui.js` عناصر الواجهة العامة فقط مثل زر المظهر ومؤشر القراءة والتنقل النشط؛ ولا يغيّر نصوص الدروس.
- **تعديل درس:** افتح الملف على GitHub واضغط القلم، ثم Commit، وانتظر دقيقة واضغط Ctrl+Shift+R.
- **درس جديد:** انسخ `content/_template-first-subunit.html` (الأول في المجزوءة) أو `content/_template-subunit.html`.
- **صفحة جاهزة من مصدر آخر:** استبدل وسم `<style>...</style>` فيها بالسطر `<link rel="stylesheet" href="../assets/site.css">` (أو أرسلها لي لأطبّق التصميم).
- **الصفحة الرئيسية والعناوين:** `assets/config.js` · **التصميم العام:** `assets/site.css` و`assets/home.css` · **تفاعلات الواجهة:** `assets/ui.js` و`assets/app.js`.

## فحص ما قبل النشر

قبل رفع التعديلات، شغّل من مجلد المشروع:

```bash
node scripts/check-site.mjs
```

يفحص السكربت وجود الملفات والروابط المحلية، وتطابق عناوين الصفحة الرئيسية مع عناوين الدروس، وتكرار المعرّفات، وبيانات SEO الأساسية، وصحة JavaScript. تظهر بقايا القوالب والملاحظات التحريرية كتحذيرات. لإيقاف النشر عند وجود أي تحذير أيضًا، استخدم:

```bash
node scripts/check-site.mjs --strict
```

لا يحتاج الفحص إلى تثبيت حزم خارجية؛ يكفي Node.js.

## ملاحظة حول الوحدة الرابعة

وُحّدت أسماء الدروس في الصفحة الرئيسية وعناوين الصفحات والتنقل بحسب العناوين الموجودة فعلًا داخل الملفين الحاليين: `u4-s1.html` هو «الواجب» و`u4-s2.html` هو «الحرية». لم يُعَد بناء محتوى هذين الدرسين في هذه النسخة؛ لذلك سيُظهر الفاحص تحذيرًا بوجود بقايا قالب فيهما إلى أن يُستكمَل المحتوى.

## الواجهة الجديدة

- التصميم العام بنمط Arctic هادئ، مع مساحات واضحة وبطاقات بسيطة وتدرجات زرقاء خفيفة.
- زر المظهر يبدّل بين الوضع الفاتح والداكن، ويحفظ الاختيار محليًا في المتصفح. عند عدم وجود اختيار سابق يُستخدم إعداد النظام.
- الصفحة الرئيسية تعرض خطًا زمنيًا للمجزوءات وبطاقات الدروس، مع بحث في عناوين المجزوءات والدروس.
- صفحات الدروس تعرض شريط محتويات ثابتًا، ومؤشرًا لتقدم القراءة، وتحديدًا للمحور الظاهر، وزرًا للعودة إلى أعلى الصفحة.
- محتوى الدروس لم يتغير ضمن تحديث الواجهة.
